
# NFL Team Pick App

## Description
This is a real-time NFL Team Pick application using Socket.IO, MongoDB, and Express.

## Features
- User login
- Real-time updates for NFL teams
- Weekly team selection with reset on Tuesdays

## Setup
1. Install dependencies: `npm install`
2. Start the server: `npm start`
3. Visit `http://localhost:5000`

## Environment Variables
- `MONGO_URI`: MongoDB connection string
- `JWT_SECRET`: Secret key for tokens

Ensure the database has the required collections.
